# To-Do-List-Application
A simple To-Do List application built with Python and Tkinter. Users can add, delete, and clear tasks through an easy-to-use graphical interface. The project demonstrates the use of Listbox, Buttons, Lists, and event-driven programming in Python.

# 📝 To-Do List App

A simple and clean desktop To-Do List application built with Python and Tkinter.

## ✨ Features

- ➕ **Add Tasks** — Type a task and click _Add Task_ (or press Enter)
- ❌ **Delete Tasks** — Select any task and remove it instantly
- 🗑️ **Clear All** — Wipe the entire list with a confirmation prompt
- 🔢 **Live Task Counter** — Always shows how many tasks are pending
- ⚠️ **Input Validation** — Warns you if you try to add an empty task or delete without selecting one

## 🚀 Getting Started

### Prerequisites

- Python 3.x installed → [Download Python](https://www.python.org/downloads/)
- Tkinter comes **built-in** with Python — no extra install needed

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/todo-list-app.git

# 2. Navigate into the project folder
cd todo-list-app

# 3. Run the app
python todo.py
```

> **Windows users:** You may use `python` or `py`
> **Mac/Linux users:** Use `python3`

## 📖 How to Use

1. **Add a task** — Type in the input field and click **Add Task**
2. **Delete a task** — Click on a task to select it, then click **Delete Selected**
3. **Clear everything** — Click **Clear All** and confirm the prompt
4. The **task counter** at the top updates automatically
